# Copyright and content status

## What the MIT license covers

Original source code in `app/lib`, `app/test`, `app/android` (excluding generated
files), `server/`, `tools/`, `deploy/` and the documentation is © 2026 NOT-UN3X and
Resources contributors, licensed under MIT (`LICENSE`).

"NOT-UN3X" means exactly that: this project is **not** made by, affiliated with, or
endorsed by UN3X, the developer of the original Resources game.

## What it does NOT cover

- **Third-party dependencies**: their own licenses, see `THIRD_PARTY_NOTICES.md`.
- **Original game artwork**: this project began as a compatible re-implementation of
  a discontinued commercial location-based game. Its original images (resource
  icons, mine/HQ/building art, launcher icon, backgrounds, UI graphics, country
  flags, illustrations) were never licensed for redistribution and are **not
  included in this repository or its Git history**. Every such asset was swapped for
  a generated placeholder at the same path; see `copyrightreplace/manifest.csv`
  (`copyright_status = replacement_needed`, `replacement_status = placeholder`).
- **Trademarks**: "Resources" may be a trademark of the original game's publisher.
  Using the name here does not imply affiliation or endorsement. See "Open legal
  questions" below.

## Project-owned assets

The placeholders and launcher icon variants are generated by `tools/assets.py`
and are covered by the MIT license. Rows with `copyright_status = verified` in the
manifest are cleared for redistribution.

## Contributing artwork

Only submit artwork you created yourself, or artwork under a license compatible
with redistribution (CC0, CC-BY, CC-BY-SA, MIT, …). Record the source and license
in `copyrightreplace/manifest.csv` (see `copyrightreplace/README.md`). Never submit
files extracted from the original game's APK.

## Open legal questions (manual review required before public release)

1. **Project name**: is "Resources" usable without trademark conflict with the
   original game? A distinct name may be safer.
2. **Game data**: item and building names, production rates, costs and formulas in
   `server/main.py` and `app/lib/constants.dart` were matched to the original game.
   Game mechanics and numeric facts are generally not copyrightable, but the
   selection/arrangement (EU database right) and creative names should be reviewed.
3. **Network protocol**: the server implements the original client's endpoint paths
   (`/flut23/*.php`) and payload formats for compatibility. Interoperability is
   generally permitted, but confirm this for your jurisdiction.
4. **Legacy proxy**: `UPSTREAM_PROXY_FROM/TO` can forward unimplemented requests to
   another server. It is disabled by default; do not point it at servers you are not
   authorized to use.
